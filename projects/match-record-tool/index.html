比赛记录工具

在浏览器中记录篮球、足球及自定义比赛的比分、统计数据与事件时间线。

项目介绍

一款纯前端比赛记录工具，用于现场记录比赛过程，并在赛后查看统计数据。无需安装或构建，在现代浏览器中打开项目入口即可使用。

主要功能

  • 队伍与球员管理： 管理队伍、球员、球衣号码、位置和队伍颜色。
  • 比赛配置： 支持篮球、足球及自定义运动，设置比赛时长、节次和加时规则。
  • 现场记录： 记录实时比分、计时、节次与比赛事件，支持撤销得分。
  • 统计与回顾： 记录篮球球员统计、足球球队数据和自定义数据项，查看比赛统计与事件时间线。
  • 导入与导出： 将单场比赛导出为 JSON 或 Excel，并通过 JSON 导入恢复备份。

使用与实现

使用原生 HTML、CSS 和 JavaScript，以 Hash 路由切换页面。队伍和比赛数据保存在浏览器 LocalStorage 中；清除浏览器数据前需要导出备份。Excel 导出依赖网络加载 SheetJS，JSON 导入导出不依赖该服务。
