## 项目介绍

一款可在本地离线游玩的世界杯足球经理小游戏。玩家执教 16 支国家队之一，通过阵容安排、临场换人与战术调整，争取连赢四轮淘汰赛夺冠。

## 核心玩法

- **赛事推进：** 随机生成十六强对阵，依次进行八强、半决赛和决赛；玩家淘汰后，游戏模拟剩余赛程。
- **阵容安排：** 选择 2–1 防守阵型或 1–2 进攻阵型，拖动三名首发球员确定站位，并选择替补。
- **临场指挥：** 比赛自动推进，玩家可切换攻守平衡、高位压迫、退缩防守和控制球权等战术，并在每场比赛中换人一次。
- **比赛反馈：** 高亮持球队员，通过动态记录展示进球、抢断、扑救和重新开球。
- **加时与点球：** 平局时进入加时；仍未分出胜负则按玩家指定顺序进行点球决胜。

## 使用与实现

使用 Python 和 Flask 在本机运行，默认以 SQLite 保存球队数据、赛程和比赛进度。安装依赖后可断网游玩；Windows 用户可通过仓库中的启动脚本打开游戏。
